# sub_82F52318

Leaf, 176 lines, no callees: `atan2(y, x)` in double. f1 = y, f2 = x, result f1. Called 74,951
times in the boot profile on `RwAudioCore Dac`; 22 direct call sites (TUs 52, 68, 97, 99, 100,
101), every one reads f1 through `frsp`.

Algorithm: x == 0 special-cases (y == 0 returns y, pi or -pi by the spilled sign words; else
pi/2). Otherwise it reduces t = min(|x|,|y|)/max(|x|,|y|) (octant code 2 when swapped),
applies (sqrt3*t - 1)/(sqrt3 + t) above tan(pi/12) (code + 1), runs a P(t^2)/Q(t^2) rational
built from `fmadd`/`fmul`, negates for code > 1, adds table[code] = {0, pi/6, pi/2, pi/3}.
Finally `fsel` on x reflects to pi - angle, and the sign of y (spilled word) negates.

Pool: `0x82FB5068` (+8..+179 read). Values read from the dumped image are given in the `.inc`
comments; the body loads them all, so the port is correct whatever they hold.

Stores: `stfd f1,16(r1)`, `stfd f2,24(r1)` (8 bytes each). Both sit in the CALLER's frame, above
the entry r1, and are reloaded (`lwz 16(r1)`, `lwz 24(r1)`) for sign tests. Window: `{r1+16, 16}`,
so the native run cannot read the lifted run's spill back. Reads: the pool span.

Result mask `kReturnF1`. Gates: 1 pass (leaf), 2 pass (fixed 16 bytes), 3 pass, 4 pass (f1 named).

Unsure: NaN-payload choice in the commutative `fadd`/`fmul` follows the compiler's register
allocation (vmx128-exactness cookbook rule 4); operand order is kept as lifted, which is the
best a source port can do. NaN inputs are unlikely on this path.
