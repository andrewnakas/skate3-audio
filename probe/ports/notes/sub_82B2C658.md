# sub_82B2C658

Per-channel **peaking-EQ** stage over a 256-frame block, the third member of the filter family
whose high-pass (`sub_82B26568`) and low-pass (`sub_82B27E20`) twins are verified. Args: r3 = the
filter object, r4 = the stream (`+28`/`+32` descriptor pair, `+40` format). Returns `li r3,1` on
both exits: mask `kReturnR3`. 386 lifted lines, 66,500 boot calls, `RwAudioCore Dac`.

Object (plain offsets, nothing in `rw_audio_structs.h`): `+42` u8 channel count (re-read on every
loop test), `+52` frequency numerator, `+60` linear gain, `+68` Q, `+72` 16-byte history per
channel (so at most 8 channels before `+200`), `+200` s32 bypass flag, `+204..+220` the five
coefficients `sub_82B43AF8` consumes, `+224/+228/+232` cached warp/gain/Q.

Maths: `w = clamp(f52 / format[12] * k, 0x822F8E7C, 0x822F8E80)`, Q clamped to
`[0x82099280, 0x820996EC]`, `A = sqrt(gain)`, `alpha = sin w / (2Q)`: RBJ peaking with
`a0 = 1 + alpha/A`, stored `{-2cos w, 1-alpha/A, 1+alpha*A, -2cos w, 1-alpha*A} / a0`. Constants
computed as `((imm & 0xFFFF) << 16) + off`; 2.0/-2.0/1.0/0.0 match the values sub_82B43CC0's note
read out of the image.

Paths: gain == 1.0 (tested on the entry load of `+60`, before any store): if `+200 == 1` zero the
history for each channel and store 0 at `+200`; then store `+224/+228/+232` and return -- **no
kernel and no swap**. Otherwise: `+200 := 1` if it read 0; rebuild the coefficients unless warp,
gain and Q all equal their caches (stores 228, 232, 224, then 204..220); run `sub_82B43AF8`
(r3 = history, r4 = B channel i, r5 = A channel i, r6 = +204, r7 = 256) per channel; swap
`+28/+32` (both loaded before both stored).

Callees, all GuestCall: `sub_82F4DED0`/`sub_82F4DFB0` (sin/cos, own frame only, as in the verified
sub_82B26568 / sub_82B269C0) and `sub_82B43AF8` (verified; writes `[r4, +1024)` and `r3+0..15` at
r7 = 256, never reaches `sub_82B43978`). The history walk is `addi r3,r3,16` on the r3 the callee
left -- read from ctx.r3, as sub_82B26568 does. `stwu r1,-192` is reproduced (callees spill below
r1). r26-r31/f26-f31 are never written by Native.

Windows (mirrors `sub_82B26568.inc`, which verified the same loop): `[obj+72, obj+236)` one span;
filtering path adds `stream+28` (8) and one 1 KB span per destination channel. Returns false for
a null object/stream/descriptor/channel, a count above 8, an object or channel that wraps 2^32,
and whenever a declared write overlaps a word re-read during the call (dst descriptor `+4`/`+14`,
obj `+42`; the object span against `stream+28..35`). Gates 1-4 pass. STATUS pending.

Unsure: the Q clamp constants' values were not read from the image (only their addresses are
computed); the port loads them through the guest map, so it does not depend on them.
