# sub_82B22678

Leaf, 119 lines, no callees and no direct callers: reached through a function pointer (a DSP
plug-in process routine, by shape). Called 52,994 times in the boot profile on `RwAudioCore Dac`.
Hard clipper: r3 = effect state (u8 channel count `+42`, f32 clip level `+52`), r4 = buffer pair
(descriptor pointers at `+28` source and `+32` dest; descriptor = {`+4` float* data, `+14` u16
channel stride in samples}). Returns r3 = 1 on every path.

If level < 100.0f (pool `0x820ED57C`; NaN or >= skips everything): for each channel, 256 samples
`src[k]` -> dest = level if > level, else -level (level * -1.0f pool `0x8216DEE0`, `fmuls`) if
< -level, else the sample (single round trip, so an sNaN is quieted as in the lifted form). Then
swaps the pair: `[r4+32] = source`, `[r4+28] = dest` -- also when the channel count is 0.

Stores: `stfs` at `dst_data + channel*dst_stride*4 + 4k` (4 bytes, 256 per channel);
`stw r5,32(r4)`, `stw r6,28(r4)`. `std r31,-8(r1)` is the leaf's own red zone, not reproduced.
Windows: `{r4+28, 8}` plus one 1 KB span per channel, from entry state. The loop reloads both
descriptors per channel after earlier stores, so Windows() returns false if any dest span
overlaps a descriptor's `+4`/`+14` field (the census's 3 gate-2 suspects), or wraps 2^32.
Budget: 31 channels max (32 spans, 31,752 bytes); more returns false.

Result mask `kReturnR3`: the caller is indirect and unread here, but r3 is the constant 1 on both
paths, so comparing it cannot false-diverge. Gates: 1 pass, 2 pass (conditional, above), 3 pass,
4 pass. Reads recorded: state, both pool singles, both descriptors, per-channel source spans;
above 27 channels the per-channel source reads overflow the 32 read spans and are dropped from
the vector (not compared, so it affects replay only).
