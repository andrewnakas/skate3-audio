# sub_82B1CF50

- Role: leaf, `s32 f(obj*)`. Returns round-half-away-from-zero of `scale * prod(words[0..count-1])`,
  all arithmetic in single precision, as a 32-bit integer. 1,521,247 calls per boot session on
  `RwAudioCore Dac`; no direct `bl` site exists in the lifted tree (only the function-table entry in
  `skate3_init.cpp`), so it is reached through a pointer (vtable or callback).
- Object (r3), nothing in `docs/rw_audio_structs.h` names it: `+0 u8 count`, `+4 f32 scale`,
  `+8 s32 words[]` (word k at `+8+4k`). Word 0 and `scale` are read even when count is 0 or 1.
- Arithmetic: each word goes `extsw`/`fcfid`/`frsp` (exact for s32), then `fmuls` chains left to
  right in word order: words 1..4k in an unrolled-by-4 loop (`quads = ((count-5)>>2)+1`, entered
  when `count-1 >= 4`), the remainder in a 1-word loop starting at `next = 4*quads+1` (or 1).
  Then `fmuls` by `scale`, `fcmpu` against 0.0f (0x82165A10): `< 0` takes `fsubs 0.5f`, anything
  else (including NaN) takes `fadds 0.5f` (0x8209975C), then `fctiwz`. Constants read from the
  validated image dump (`probe/harness/out/image/g_8200.bin`; the code bytes at 0x82B1CF50 match).
- Stores: eight, all to the function's own red zone (`std`/`stfd` at `r1-32..r1-8`, spill-to-`lfd`
  and the `fctiwz` spill read back by `lwz r3,-4(r1)`). None to guest state; not windowed.
- Result: r3 = zero-extended low word of the `fctiwz` value (`0x80000000` for NaN or below
  INT_MIN, `INT_MAX` above it). f0/f1/f13 are left as scratch only. Mask `kReturnR3`.
- Windows: no writes. Reads `obj[0 .. 8+4*max(count,1))` (at most 1,028 bytes) and the two 4-byte
  rodata constants. Always enumerable; returns true.
- Gates: 1 pass (leaf, no imports/indirect/lock), 2 pass, 3 pass (no timebase), 4 pass (r3).
- Unsure: only that the caller reads r3 alone -- inferred from the ABI shape (`stfd`/`lwz r3`/`blr`
  epilogue) because no static call site exists to confirm it. `fmuls` of two singles held as
  doubles is exact before the `frsp`, so the native `double(float(a*b))` matches bit for bit;
  under flush-to-zero the harness's `disableFlushModeUnconditional` points are kept as lifted.
- Not on any manifest: `audio_ports/ports_66.manifest.inc` is generated by `probe/ports/queue.py`;
  it was not edited.
