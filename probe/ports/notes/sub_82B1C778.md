# sub_82B1C778

Leaf, 59 lines, no callees, no imports, no timebase. Called ~1.0M times per boot session on
`RwAudioCore Dac`; reached through a function pointer (no `bl 0x82b1c778` anywhere in the lifted
tree -- the address appears only in the function table), so no call site was readable. r3 is set
by `li` on every path immediately before `blr`, so it is the return value: mask `kReturnR3`.

Object (r3, 24 bytes; nothing in `docs/rw_audio_structs.h` names it): int32 bounds at +0/+4
(entry window) and +8/+12 (exit window), u8 latch at +16, u8 edge pulse at +17, int32 value at +20.
All compares are signed 32-bit (`cmpw`).

Behaviour: value in [+0,+4] and +16 == 0 -> store 1 at +16, store 1 at +17, return 1.
Value in [+0,+4] and +16 != 0 -> store 0 at +17, return 0 (no store at +16).
Otherwise: if value in [+8,+12] store 0 at +16; then store 0 at +17, return 0.
A hysteresis trigger: +16 is the latched inside-state, +17 (and r3) is the rising edge.

Stores: `r3+16` (u8, two of the three paths), `r3+17` (u8, every path). Order preserved: +16 then +17.
Window: `{r3+16, 2}` unconditionally -- covering +16 on the path that does not write it is harmless.
Read: `{r3, 24}`.

Gates: 1 pass (leaf), 2 pass (entry-derived, 2 bytes), 3 pass (no time), 4 pass (stores plus r3).
Unsure: only the caller identity; it does not affect the compare since r3 and both bytes are visible.
