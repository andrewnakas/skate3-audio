# sub_82B34268

Leaf, 11 lines. Stores `r6` as a u16 at `object+460` (`sth r6,460(r11)`), returns 0 in r3.
Same shape as the verified sub_82B29278 (which stores at +364); nothing in
docs/rw_audio_structs.h names +460 (0x1CC), so it stays a plain constant.
Arguments: r3 = object, r6 = value (r4, r5 unused). One store, entry-derived
(provenance: base r11 = r3, cls=entry). No callees, no timebase, no locks. Gate 1-4 clean.
Window: `{r3+460, 2}`. Result: r3 (the `li r3,0` is the only register left behind that a
caller could read; r11 is volatile scratch).
Boot profile: 223,568 calls on RwAudioCore Dac -- the hottest leaf ported so far, so a
divergence here will show within seconds of arming.
