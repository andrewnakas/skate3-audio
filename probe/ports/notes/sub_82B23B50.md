# sub_82B23B50 — per-channel gain ramp over a double-buffered block

Lifted: `skate3_recomp.67.cpp:14525`, 119 lines. Thread `RwAudioCore Dac`, boot 341,223 calls.
One callee: `sub_82B3C098` (gain-ramp copy, 1024 bytes per call, already ported — pending).

## Arguments

- `r3` gain object: `+42` u8 channel count, `+52` single target gain, `+56` single applied gain.
- `r4` descriptor pair: `+28` source descriptor, `+32` destination descriptor, swapped on exit.
  Each descriptor: `+4` float run for channel 0, `+14` u16 singles between channels.
- `r5` byte flag; non-zero means "no ramp this block": applied is latched to target up front, so
  the step below comes out zero.

Nothing in `docs/rw_audio_structs.h` names either object; the constant names describe the
arithmetic only.

## What it does

`step = (target - applied) * <single at 0x822F87E0>` (fsubs then fmuls, never fused) is computed
once and passed to every `sub_82B3C098` call in `f2`, with `f1` re-read from `+56` each
iteration. Channel `i` copies `src[+4] + stride*i*4` to `dst[+4] + stride*i*4`, 256 singles.
Then the pair is swapped and `applied = target`.

`f2` is set once and the callee never writes `f1`/`f2` (it clobbers `f0`, `f8`-`f13`), so the
original's reuse across iterations is sound; reproduced as written, not hardened.

The rodata address is `((-32208 & 0xFFFF) << 16) - 31232 + 480 = 0x822F87E0`, computed, not read
off by eye. The value is loaded through the guest map.

## Windows

True on every path, with three predicted refusals:

1. channel count > 24 — the 32-span / 32 KB budget (1024-1151 bytes per channel).
2. a block that would wrap the top of the 32-bit map.
3. a block that overlaps `object + 52..59`, `pair + 28..35`, or either descriptor's `+4..+15`.
   The loop re-reads all of those *inside* the loop, so an aliasing block would make the
   addresses of later iterations something produced during the call — gate 2 by construction.
   Never observed; predicted rather than assumed away.

## Gates

Gate 1 pass (the single callee is a leaf with no lock, allocation, import or indirect call —
`dcbzl` lowers to a `memset` of a cache line and replays). Gate 2 pass under the refusals above.
Gate 3 pass (no timebase). Gate 4: the tail `li r3,1` is the return value, so the mask is
`kReturnR3`; every other effect is in the declared windows. STATUS `pending`.

## Unsure
