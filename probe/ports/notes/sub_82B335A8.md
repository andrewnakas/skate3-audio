# sub_82B335A8

Parses a stream's packed, MSB-first bit header into voice `index`'s 80-byte record and 48-byte
control slot. Non-leaf, 267 lifted lines, 1932 calls per boot, `RwAudioCore Dac`. Only caller:
`sub_82B33D40` (gate 1), which passes `produced + 4` and never reads r3 afterwards: `kReturnNone`.

Arguments: r3 = system object, r4 = voice index, r5 = stream pointer or 0. Records, derived once
at entry exactly as in `sub_82B33D40.inc` (field names mirrored from there, a reading):
`voice = *(obj+96) + 80*index`, `slot = obj + u16(obj+464) + 48*index`.

r5 == 0: defaults -- `slot+47`=0 (u8), `slot+16`=single at 0x8231A844, `slot+20`=0x7FFFFFFF,
`slot+24`=-1, `voice+72`=255, `voice+73`=1, `voice+16/+12/+8`=0, `voice+76`=1.
r5 != 0: a leading 'H' byte skips 4; then fields of 4,4,6,18,2,1,29 bits go to `voice+76`,
`voice+72`, `slot+47` (+1), `slot+16` (fcfid/frsp, round-tripped through r1+88), `voice+73`, a
local flag, `slot+20`. Flag set: 32 bits to `slot+24`, else -1. `voice+73` is **reloaded**;
== 2: 32 bits to `voice+16`. Flag set: mode 1 reads 32 bits into `voice+12`; mode 2 does too when
`s32(slot+24) >= s32(voice+16)` (both reloaded); otherwise `voice+12`=0. Last, `voice+8` = stream
+ header bytes (the reader's cursor >> 3), a 64-bit add truncated by the store.

Callee: `sub_82B26B70` (verified), the bit reader, called 7-10 times through `GuestCall` on a
{data, cursor} pair at r1+80. Its `Windows()` (recomp/src/audio_ports/sub_82B26B70.inc, mirrored)
writes only the cursor word, which is at r1+84 in this function's frame, so it adds no window.
The `stwu r1,-160` frame IS reproduced, so the reader's `std r31,-8(r1)` does not land on the pair.
r26-r31 are never written by the body (locals throughout), so no restore is needed.

Window: 5 spans, 28 bytes -- `slot+16` (12), `slot+47` (1), `voice+8` (12), `voice+72` (2),
`voice+76` (1). Both bases are loaded at entry only, so every address is entry state. Returns
false for a null object or a record that would wrap 2^32. Reads: `obj+96`, `obj+464`, the
default single, and the stream's first 4 + 20 + 1 bytes.

Gate verdict: passes all four -- no lock, no indirect call, no timebase, one replayable callee.
Unsure: the field meanings (they look like an EA SNR header -- version, codec, channels-1, sample
rate, type, loop flag, sample count, loop start, loop end, loop offset -- but nothing here proves it).
