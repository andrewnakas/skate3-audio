# sub_82B222D8

Per-block driver for one streamed voice. `skate3_recomp.67.cpp:10574`, 419 lines, 111,801 boot
calls on `RwAudioCore Dac`. Callees `sub_82B3D8E0`, `sub_82B225A0`, plus one `bctrl`.

- Args: r3 = voice, r4 = stream (`+28`/`+32` two buffer descriptors, `+40` -> format, `format+12`
  the float rate). Returns `li r3,1` on every path, so `kReturnR3` is honest here.
- Constants: `0x82B3D4F8`/`0x82B3D578` (the mixer pair), `0x82165A10` zero, `0x8209975C` half,
  `0x820ED5E8` level limit, `0x822F8E60` level floor (`0x82300000 - 31232 + 2144`).
- Stores, in order: `self+76`, `+80` (the pair), `+104` (= self+76), arena`+32` (lowered 2816),
  `+108`, `+128` (704); then per state `self+92/+96` (mixer level pair, via stfs), block
  (`self+100`) `+32 +36 +40 +44 +52` u32 and `+56` u8, `self+64`; after `sub_82B3D8E0` the swap of
  stream `+28`/`+32`; last, arena`+32` restored from the value read on entry.
- States at `+64`: 0 = start (reset the mixer, rewind the block, go to 1), 1 = run (go to 2 when
  the length exceeds `min(block+32, block+12)`), 2 = drain (back to 1 once it fits), 0 again when
  the length rounds to <= 0. `>= 3` skips to the tail. The start arm stores `+96` before `+92`.
- Gate 1, depth 0: `bctrl` at `0x82B224DC` calls through `self+80`, which this call itself set to
  `sub_82B3D578` a few instructions earlier (reloaded, so reproduced as indirect). `sub_82B3D8E0`
  is gate-1 in its own right (two `bctrl` through the mixer). Would-be windows are the stores above
  plus both callees' write sets; `Windows()` returns false.
- Unsure: the names of `block+12` and `self+52`; whether `+64 >= 3` ever occurs. The frame is
  reproduced (stwu) but the r26-r31/f30/f31 spills are not, since those registers are never
  written; `lr` is set before each `bl` so callee spills match.
