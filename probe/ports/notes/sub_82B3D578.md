# sub_82B3D578

Leaf, 18 lines. Loads the single at `0x82165A10` (the `.rdata` cell the queue producer's liveness
path also reads, documented as 0.0f in `docs/shadow-harness.md`) and stores it to `f32[r3+16]`
then `f32[r3+20]`. Write set `{r3+16, 8}`; read set the constant. `kReturnNone` -- r3 is unchanged
and every register it touches (r11, f0) is volatile.

The port does not copy the loaded word straight through. The lifted form widens the single to a
double and narrows it back before each store, which is exact for every value a single can hold
but quiets a signalling NaN. Reproducing the round trip makes that case match by construction
rather than by an argument that the cell is never a signalling NaN.

Only 10 calls in the boot profile, so this is thinly exercised whatever the divergence figure says.
