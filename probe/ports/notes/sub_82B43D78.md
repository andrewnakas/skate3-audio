# sub_82B43D78

Builds the five normalised coefficients of a high-shelf biquad. Args: r3 = the 20-byte
coefficient block, f1 = w (radians per sample), f2 = the linear shelf gain; A = sqrt(f2). Returns
nothing. The only caller is sub_82B26740 (call at 0x82B267E0, r3 = obj+196), which afterwards
stores obj+216/+220 and never reads f1, so kReturnNone compares everything observable.

Callees, both through GuestCall: **sub_82F4DED0** (sine, on w) and **sub_82F4DFB0** (cosine, on w)
-- the same pair port_82B43CC0 and port_82B269C0 call. Each writes only its own frame below r1.
Census: gate1 pass, depth 0, closure size 2.

Constants, computed as ((lis_imm & 0xFFFF) << 16) + offset and read out of the dumped image:

    0x8231A844 = 1.0   0x822F8E50 = 0.70710653 (0x3F3504EF, NOT the nearest float to 1/sqrt 2)
    0x82060C50 = 2.0   0x82094178 = -2.0

Worked through, the arithmetic is the RBJ high shelf at S = 1, alpha = sin(w) * 0.70710653, laid
out as sub_82B43CC0's block: [a1, a2, b0, b1, b2] / a0.

Stores (f32 each): r3+0, +4, +8, +12, +16. Nothing else outside the frame.

Kept deliberately: sqrt(A) is four separate `fsqrts` (identical results, kept as instructions);
1/a0 is one `fdivs` and every coefficient is a MULTIPLY by it; fmadds/fnmsubs stay fused, with
fnmsubs as -fma(a,c,-b) exactly as lifted; operand order of every multiply kept (NaN choice).
`stwu r1,-128(r1)` reproduced for the reason port_82B43CC0 gives (both callees write below r1).
r31, f29-f31 saved and restored in host locals.

Window: one 20-byte span at r3, from entry state; false only for r3 == 0.

Gates: none fire. STATUS pending -- only 4 calls in a boot, so a session may compare few vectors.

Unsure: the name "high shelf" is from the algebra, not from any symbol.
